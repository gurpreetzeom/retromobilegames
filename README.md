# Retro Mobile Games

Nokia 1100-inspired browser simulator with fan-made Space Impact+ and Snake II recreations.

## Play and controls

Open `dist/index.html` in a browser or serve the `dist/` directory with any static host. No installation or build is required.

Use 2/8 to select a game and 5 or the centre key to open it. In Space Impact, move with 2/4/6/8, hold 5 to fire, and press * for a special weapon. In Snake II, steer with 2/4/6/8. # or C pauses. Arrow keys also work on desktop.

## Concurrent players

Every browser tab runs an independent game session. Multiple visitors can play simultaneously without sharing game state. High scores stay in each browser; this is not online head-to-head multiplayer.
